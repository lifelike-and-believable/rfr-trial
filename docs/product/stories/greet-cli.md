# Greet from the command line

As someone trying the library, I want to greet a person from the command line, so that I can see what the library does without writing code.

## Acceptance criteria

- Running the command with a name prints a greeting for that name.
- I can ask for the greeting in capitals.
- Running it without a name tells me how to use it.
